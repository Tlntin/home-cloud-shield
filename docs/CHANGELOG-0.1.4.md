# 更新日志 / Changelog — v0.1.4

## [0.1.4] - 2026-11-28

### 中文

- **自定义规则**。内置列表支持编辑已添加的规则。导入的规则文件支持逐条可视化编辑和全文编辑，列表会标记注释并单独计数。
- **规则预览**。调整域名范围、自定义通配、DNS 查询类型或优先级时，会实时显示规则原文，并说明会拦截或放行哪些查询。带图片条件的规则会说明当前 DNS 引擎如何处理。
- **平板横屏**。侧栏选项与右侧页面同步切换。规则编辑器使用加宽的系统居中弹窗，左侧编辑、右侧预览，保存和更新操作放在标题栏。

GitHub 附件为未签名 HAP，可自行签名后安装。

### English

- **Custom rules**. Edit existing entries in built-in lists. Imported files support per-rule visual editing and full-text editing, with comments labeled and counted separately.
- **Rule previews**. Changes to domain scope, wildcard patterns, DNS query type, or priority update the rule text and explain which queries are blocked or allowed. For rules with an image condition, the preview explains how the current DNS engine handles it.
- **Landscape tablets**. The content pane follows the selected sidebar item. The rule editor opens in a wider system dialog, with editing and preview side by side and Save and Update actions in the header.

The GitHub asset is an unsigned HAP that you can sign before installing.
