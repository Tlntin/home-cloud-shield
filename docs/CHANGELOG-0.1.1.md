# 更新日志 / Changelog — v0.1.1

## [0.1.1] - 2026-11-21

### 中文

#### 新增

- **应用接续**。从系统发起接续，在另一台设备打开应用并接收过滤配置，源设备可以继续过滤。
- **手动同步配置**。在应用内选设备，同步过滤规则、订阅、DNS 设置和分应用配置，并查看对方是否确认接收。同步时会合并列表并保留接收端已有条目。

前往 **我的 → 设置 → 跨设备同步** 开启功能。同一华为帐号下的两台设备都需要开启。

### English

#### Added

- **App continuation** opens the app on another device with your filtering settings, while the source device can keep filtering.
- **Manual settings sync** lets you select a device, send filter rules, subscriptions, DNS settings, and per-app routing, and see whether the receiving device confirmed delivery. Existing list entries on the receiving device are kept when the lists are merged.

Enable **Me → Settings → Cross-device sync** on both devices signed in to the same HUAWEI ID.
