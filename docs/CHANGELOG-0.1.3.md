# 更新日志 / Changelog — v0.1.3

## [0.1.3] - 2026-11-26

### 中文

- **规则配置**。内置规则和导入规则分组显示，卡片按可用宽度自动切换单列、双列或三列。导入在线订阅时可填写备注名称。
- **我的与外观**。语言可直接在「我的」页面通过下拉菜单切换。「外观」提供六套可预览配色，支持分别选择浅色、深色或跟随系统。
- **防护设置**。过滤引擎可通过下拉菜单切换，DNS 缓存和 IPv6 解析等选项集中显示。VPN 启动超时会提示重试，并恢复相关操作。
- **应用与订阅**。添加应用时可手动填写并校验包名。因合规需要，移除了内置服务屏蔽、推荐规则库和应用快捷项，已保存的订阅和应用可继续使用。

GitHub 附件为未签名 HAP，可自行签名后安装。

### English

- **Rule configuration** groups built-in and imported rules and adapts to one, two, or three columns. You can give imported subscriptions a custom name.
- **Me and Appearance** add a language dropdown on Me and six color themes with previews. Choose a color theme independently of light, dark, or system display mode.
- **Protection settings** include an engine dropdown and group DNS caching with IPv6 lookup settings. When VPN startup times out, the app shows a retry message and makes the controls available again.
- **Apps and subscriptions** support manual entry and validation of bundle names. For compliance reasons, this release removes the built-in service blocking list, recommended lists, and the quick pick for apps. Saved subscriptions and apps remain available.

The GitHub asset is an unsigned HAP that you can sign before installing.
